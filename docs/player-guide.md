# KubejsRPG 설치 안내 (친구들에게 보낼 글)

아래 내용을 디스코드 공지 등에 그대로 붙여넣어 쓰면 됩니다.

---

## 🎮 KubejsRPG 서버 접속 방법

**1. 런처 설치**
- `KubejsRPG-Setup.exe` 를 받아서 더블클릭하세요. 런처를 인터넷에서 받아(약 100MB) 물어보는 것 없이 설치하고 바로 켜요.
- ⚠️ 처음 실행하면 **"Windows의 PC 보호"** 창이 떠요. 개인이 만든 프로그램이라 코드 서명이 없어서
  그런 거예요. **추가 정보 → 실행** 을 누르면 설치돼요. (처음 한 번만 그래요)
- 바탕화면과 시작 메뉴에 **KubejsRPG** 아이콘이 생겨요. 관리자 권한은 필요 없어요.

**2. 로그인**
- 바탕화면의 **KubejsRPG** 실행 → 오른쪽 위 **로그인** → 마인크래프트 자바를 산 마이크로소프트 계정으로 로그인.
- 로그인은 처음 한 번만 하면 돼요.

**3. 게임 시작**
- **설치 후 시작** 버튼을 누르면 모드팩·자바·네오포지를 알아서 받고 서버로 바로 접속해요.
- 처음엔 받을 게 많아서 몇 분 걸려요. 다음부터는 바로 켜져요.

**업데이트는?**
- 런처를 켜면 새 패치가 있는지 알아서 확인하고, 패치노트와 함께 **업데이트 후 시작** 버튼이 떠요.
  누르기만 하면 바뀐 파일만 받아요. 따로 받을 건 없어요.
- 키 설정, 그래픽 설정, 미니맵 데이터 같은 내 설정은 업데이트해도 그대로예요.

**문제가 생기면**
- 런처 **설정** → **파일 검사/복구** 를 눌러보세요.
- 그래도 안 되면 **설정 → 로그 폴더 열기** 에서 `latest.log` 파일을 관리자에게 보내주세요.
- 램이 부족하면 **설정** 에서 메모리를 조절할 수 있어요 (6GB 이상 권장).
- "이 계정에는 마인크래프트 자바 에디션이 없습니다" 가 뜨면, 다른 마이크로소프트 계정으로 로그인한 거예요.
  로그아웃 후 자바를 산 계정으로 다시 로그인하세요.

## 관리자 메모

- exe 는 런처 자체를 고쳤을 때만 다시 나눠주면 됩니다. 모드팩 패치는 런처가 알아서 받습니다.
- "PC 보호" 경고를 없애려면 코드 서명이 필요합니다 (README 의 "알아둘 점" 참고).
